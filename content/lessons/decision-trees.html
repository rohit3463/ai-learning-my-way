The goal

A decision tree classifies a point by asking a series of yes-or-no questions, like the game Twenty Questions. Each question looks at one measurement and compares it with a threshold:

\[ \text{is } x_1 > 4.5\,? \]

Depending on the answer you go left (no) or right (yes) and ask the next question, until you reach an answer. Learning a tree means choosing which questions to ask, and in which order.

Step 1: measure the mess

A good question splits the points into groups that are each mostly one class. To compare questions we need a number for how mixed a group is. The usual choice is Gini impurity. With two classes, where \(p\) is the share of class 1 in the group:

\[ \text{Gini} = 1 - p^2 - (1 - p)^2 \]
Group\(p\)Gini
all one class0 or 1\(1 - 1 - 0 = 0\): no mess
3 of one class, 1 of the other0.25\(1 - 0.0625 - 0.5625 = 0.375\)
half and half0.5\(1 - 0.25 - 0.25 = 0.5\): the most mess

Step 2: score a question

A question splits the group into a "no" side and a "yes" side. Its score is the Gini of each side, weighted by how many points went there:

\[ \text{mess} = \frac{n_{\text{no}}}{n} \times \text{Gini(no)} + \frac{n_{\text{yes}}}{n} \times \text{Gini(yes)} \]

Lower is better. A perfect question leaves both sides pure and scores 0.

Step 3: find the best question

Try every measurement, and for each one try every useful threshold: the halfway points between neighbouring values in the data. Score each candidate and keep the one with the least mess (Act III).

A worked example by hand

Ten points with labels 0 and 1:

\((x_1, x_2)\)(2, 7)(3, 6)(4, 8)(5, 3)(6, 2)(7, 4)(6, 7)(8, 6)(3, 2)(7, 8)
label0001110101

Before any question, five of the ten are 1s, so \(p = 0.5\) and the Gini is \(0.5\).

Question: is \(x_1 > 4.5\)?

  • No side: \((2,7), (3,6), (4,8), (3,2)\). All four are 0, so Gini \(= 0\).
  • Yes side: the other six, five 1s and one 0. \(p = 5/6\), so Gini \(= 1 - (5/6)^2 - (1/6)^2 = 0.278\).
\[ \text{mess} = \frac{4}{10} \times 0 + \frac{6}{10} \times 0.278 = 0.167 \]

Question: is \(x_2 > 5\)?

  • No side: \((5,3), (6,2), (7,4), (3,2)\), three 1s and one 0: Gini \(= 0.375\).
  • Yes side: six points, two 1s and four 0s: Gini \(= 1 - (1/3)^2 - (2/3)^2 = 0.444\).
\[ \text{mess} = \frac{4}{10} \times 0.375 + \frac{6}{10} \times 0.444 = 0.417 \]

The first question is much better. After checking every candidate, \(x_1 > 4.5\) turns out to be the best, so it becomes the root of the tree.

Step 4: grow the tree

Repeat the same search inside each side, using only the points that landed there. The no side above is already pure, so it becomes a leaf that answers 0. The yes side still has one 0 among five 1s, so we search for its best question, and so on.

Stop splitting a group when:

  • it is pure (Gini is 0), or
  • the tree has reached a chosen maximum depth, or
  • no question reduces the mess.

A leaf answers with the majority label of the training points that reached it. On the page, each question is a straight cut, so the tree carves the plane into boxes (Act IV).

Too many questions

If you let it, a tree keeps splitting until every leaf is pure, even if that means drawing a tiny box around one noisy point. It then scores 100% on the training data but worse on new data: it has memorised the noise instead of learning the pattern. This is called overfitting (Act V).

The usual cure is to limit the depth, or require a minimum number of points in each leaf, and choose that limit by checking accuracy on points kept aside for testing.

Predicting

To classify a new point, start at the root, answer each question with the point's measurements, and follow the branches until you reach a leaf. The leaf's label is the answer.

A great strength of trees is that you can read the reason for every answer: "because \(x_2 \le 1.0\), and \(x_1 > 0.2\), and \(x_2 > -0.5\)" (Act VI).

Other ways to measure mess

Gini is not the only choice. Another common one is entropy:

\[ \text{entropy} = -p \log_2 p - (1 - p) \log_2 (1 - p) \]

It is also 0 for a pure group and largest (1) for half and half. The best split found with entropy is usually the same as with Gini. Choosing splits by how much entropy they remove is called information gain.
